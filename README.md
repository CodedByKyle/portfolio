# Portfolio

Source for Kyle Robertson's portfolio site. Plain HTML, CSS and JavaScript with no build step.

- `index.html` holds all the text.
- `styles.css` is the layout and type.
- `script.js` runs the grain background, the cursor and the screenshot viewer.
- `images/` holds the project screenshots.

## Run it locally

```bash
python3 serve.py
```

Then open http://localhost:4173. `serve.py` is the standard Python file server with caching turned off, so a reload always shows what is on disk.
